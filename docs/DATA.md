# 数据去向和保留

| 数据 | 处理或保存位置 | 访问与删除边界 |
| --- | --- | --- |
| 原始录音、分析与作品 | 主 API 的私有磁盘数据目录 | 用户按归属访问，可主动删除对应主服务资源 |
| 用户、密码哈希、会话、项目 | PostgreSQL | 通过账号 API，密码不保存明文 |
| GPU 输入、中间文件、音轨 | 独立 GPU 环境 | 后端受控连接，需独立清理策略 |
| Gemini 分析输入 | 用户同意后送入所配 API | 第三方保留规则依服务条款 |
| 翻译描述 | 所配文字模型 API | 发送创作文本，不作为原录音分析替代 |
| 设备原录音 | 原设备 | 主服务删除不等于物理设备删除 |

当前没有自动 7 天或 30 天到期删除，不能把设计目标写为已实现。删除主服务数据不自动删除 GPU 副本、设备录音、可选归档或备份。管理员部署时必须定义自己的数据保留、备份与清理策略。

公开仓库只含团队提供的演示媒体，不包含真实用户数据、数据库、日志或内部部署快照。
